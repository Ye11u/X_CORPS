# Server 연결 방법 

동일 네트워크에서 라즈베리파이(송신) -> GUI(수신)
라즈베리파이에 키보드, 모니터를 연결하지 않고 노트북과 랜선을 이용하여 접속

## 준비물 

- 멀티탭 (1~2구)
- LAN 케이블
- LAN-to-C ot LAN-to-USB 변환 케이블
- 라즈베리파이 전원 장치
- 카메라, 카메라 케이블
